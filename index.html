Modelo de Segurança do Windows
ComponenteFunção / relevância
Token de acessoIdentidade do processo: SID, grupos, privilégios, integrity level. Primário (processo) vs Impersonation (thread)
SID / RIDSecurity Identifier de user/grupo. RID = parte final (500=Administrator, 501=Guest)
Integrity LevelLow · Medium · High · System. Processos High não são afectados por Low (MIC)
Privilégios vs PermissõesPrivilégios = acções no sistema (SeDebug, SeBackup). Permissões = acesso a objectos (ACL)
DACL / SACLDACL decide acesso (Allow/Deny). SACL define auditoria → aparece no Event Log
LUIDLogon session ID — cada início de sessão tem uma LUID única (ver 4624, 4672)
LSASSLocal Security Authority — valida credenciais, gera tokens. Alvo nº1 de credential dumping (ver Sysmon ID 10)
SAM / SECURITY / SYSTEMHives com contas locais, políticas e chaves de arranque (ver Registo)
UACSepara token normal (Medium) de token admin (High). Admin Approval Mode
Authentication PackagesNTLM · Kerberos · Negotiate (SPNEGO) · CredSSP · registadas em HKLM\SYSTEM\...\Lsa
⚠ Privilégios de alto risco SeDebugPrivilege (injectar em LSASS) · SeImpersonatePrivilege (Potato attacks) · SeBackupPrivilege (ler SAM/SYSTEM) · SeTakeOwnershipPrivilege · SeLoadDriverPrivilege (BYOVD) · SeTcbPrivilege

IOC vs TTP vs Artefacto — diferenças
TermoDefiniçãoExemploDurabilidade
IOC Indicator of Compromise — valor estático que sinaliza intrusão Hash SHA256, IP C2, domínio, chave de registo Baixa (muda com recompilação/infra nova)
TTP Tactics, Techniques & Procedures — comportamento do atacante Uso de certutil -urlcache, DCSync, Kerberoasting Alta (persiste entre campanhas)
Artefacto Elemento físico/lógico recolhido durante o incidente Ficheiro EVTX, hive do registo, RAM, MFT Permanente enquanto preservado
IOA Indicator of Attack — comportamento observado em tempo real Sequência: macro → cmd → download → persistência Alta (foco na cadeia, não no valor)
💡 Pyramid of Pain Hash → IP → Domínio → Artefacto de rede/host → Ferramenta → TTP. Detectar no topo (TTP) é o que mais custa ao atacante. É por isso que Sigma e hunts comportamentais valem mais do que listas de IOCs.
